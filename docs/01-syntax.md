**Definition 1.1 (Alphabet).** `[DRAFT]`
The alphabet of NPL consists of:
- a countably infinite set `Atom = {p₀, p₁, p₂, …}` of propositional atoms
  (written informally p, q, r, …);
- the unary connective ¬ (negation);
- the binary connectives ∧ (conjunction), ∨ (disjunction), ⊕ (harmonization);
- parentheses.

> *Lean:* atoms are encoded as `Nat` (`Nullivance.Syntax.Formula.atom : Nat → Formula`) · *DR:* DR-0001

**Definition 1.2 (Formulas).** `[DRAFT]`
The set `Form` of formulas is generated by the grammar

```
φ ::= p  |  ¬φ  |  (φ ∧ ψ)  |  (φ ∨ ψ)  |  (φ ⊕ ψ)      (p ∈ Atom)
```

i.e. `Form` is the least set containing `Atom` and closed under the four connectives.

*Induction principle.* Every structural-induction proof over `Form` must discharge exactly
five cases: atom, ¬, ∧, ∨, ⊕ (R6). This principle is the eliminator of the Lean inductive type.

> *Lean:* `Nullivance.Syntax.Formula` · *DR:* DR-0001 · *Depends on:* Def 1.1

**Definition 1.3 (Material conditional — abbreviation).** `[DRAFT]`
`φ ⇒ ψ  :=  ¬φ ∨ ψ`.
⇒ is *notation only*, not a primitive connective; no semantic clause and no proof rule may
treat it as primitive.

> *Lean:* `Nullivance.Syntax.Formula.impl` (a `def`, not a constructor) · *DR:* DR-0001 · *Depends on:* Def 1.2

**Convention 1.4 (Precedence).** `[DRAFT]`
Binding strength, strongest first: ¬ > ∧ > ∨ > ⊕ > ⇒. Outer parentheses are dropped.
