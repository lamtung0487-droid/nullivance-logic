# DR-0110 — Continuing an accepted stopping certificate

Date: 2026-10-29. Base: `acea786`. Status: scoped Lean proof checked.

## Claim card

Continue DR-0109's remaining inter-call obligation. Given an already certified
stop of an old observation segment ys and newly supplied finite chunks,
continue without checking or replaying ys. Preserve an existing first hit;
otherwise start from the stored endpoint and translate new hit indices by the
certified consumed count. Prove reference equality, renewed certification and
cost of this call, separately from earlier validation cost.

Adversarial cases: old hit followed by contradictory new data; exhausted empty
old segment; all new chunks empty; omitted index offset; arbitrary historical
reported cost; and rejected checkpoint followed by a firing suffix. No core
axiom or semantic definition changes.

## Certificate-preserving continuation

The implementation branches on the saved optional index. If a hit was already
found, it returns the same endpoint, index and consumed count without traversing
new chunks. Otherwise it runs DR-0107's measured chunk stop from the stored
cache, adds the saved consumed count to any new hit index and to new consumption,
and retains the new endpoint. The old input segment is only a type/specification
parameter; no runtime old-list length or old replay is needed.

The invariant ties the stored cache/index to the original first-hit run and
the consumed count to its actual tested prefix. In the exhausted branch the
saved count therefore equals length(ys). Combining those facts with the prior
append theorem proves equality to stopping on ys ++ flatten(newChunks). The
renewed certificate keeps both the reference equality and the exact count
relation. Its constructor consumes the measured continuation result once;
it does not execute the reference stop to produce the proof.

An existing hit means later chunks are not tested. Exhaustion is permission
to continue, not a verdict affirming quasivance. Indices are relative to the
combined old/new observation segment; a separate initial history preceding
that segment is not silently added to the index. Scalar soundness still needs
a verified initial cache and a prefix generated by the same scalar state.

## Historical cost is not a trusted accumulator

DR-0107's certificate constrains endpoint, index and consumed count, not its
arbitrary `cost` field. The continuation must not use that field as a verified
total. Its new cost field explicitly records **this continuation call only**.
Old costs must be accounted for separately by the actual counted caller.
The cost-irrelevance theorem permits replacing the old reported cost with any
natural number and proves the entire continuation output unchanged. Thus the
implementation is not relying on a historical number that its type never
certified.
This is not equality of the entire measured record to a hypothetical one-pass
run: the checkpoint fields agree, but costs measure different workflows.

One Option dispatch costs 1. A saved hit costs exactly 1, independent of new
chunks. On old exhaustion the exact cost is the new measured run cost plus 1,
bounded by `5Nnew + 3Bnew + 2`. This bound excludes earlier import/validation
and the earlier observation run. It also excludes arithmetic bit complexity,
allocation, stack behavior, proof construction, parsing, I/O and sensing,
using the existing abstract operation model. No constant bit-cost claim is
made for a growing saved offset.

## Validation followed by continuation

A separate entry point composes the counted DR-0109 checkpoint importer with
continuation. It imports once, charges one Option dispatch, then either returns
rejection or continues from the returned certificate. A joint theorem identifies
both its returned optional certificate and total counter. On rejection it costs
I+1 and does not inspect new chunks. On acceptance it costs I+1+C, where I is
the actual checkpoint-import cost and C is this call's continuation cost.
When the accepted old checkpoint already has a hit, the total is exactly I+2,
independent of the newly supplied chunks. The guarded erasure theorem gives
the original first-hit reference on the concatenated segments on acceptance,
and none on rejection. This proves the full entry-point behavior rather than
only correctness of an inner raw continuation function.

Consequently its upper bound is
`5(Nold+Nnew) + 3(Bold+Bnew) + 28`. Initial-cache validation against a preceding
history is still not included; q is the supplied initial cache. There is no
claim that reimporting every time avoids old-data replay. Only continuation
from an already accepted in-memory certificate does so. Serialized objects
without proofs must pass the validator again.

## Boundary regressions

From one already processed silent observation, continuing with
`[firing,silent]` yields `(index=some 1, consumed=2, callCost=8)`. Continuing
that result again with an empty chunk and a silent chunk retains index 1 and
consumed 2, with callCost=1. The new chunks in that second call are untested.
An empty certified old segment followed by two empty chunks returns no hit,
zero consumption and cost 8; chunk inspections are not free.

For the whole checkpoint-import/continuation entry point, the valid checkpoint
of one silent old reading followed by the firing suffix returns
`(some (some 1,2),34)`; a checkpoint with an incorrect consumed count returns
`(none,26)`. The valid case pays 25 for checkpoint import, 1 for Option dispatch,
and 8 for continuation. The rejected case pays 25+1 and never runs the suffix.
The old measured run includes its terminating outer-list inspection: omitting
that unit would incorrectly predict 33 and 25. These values are kernel-checked,
not estimates from output equivalence.

## Remaining obligation

Lift certified continuation to an arbitrary finite sequence of calls with a
separate verified cost ledger. Prove that summing the actual new call costs
preserves the first-hit result and yields a cumulative bound that pays initial
validation once. Do not reuse an arbitrary saved `cost` field as that ledger,
and do not count revalidation as free if raw checkpoints are reimported.

Typed checkpoint parsing/encoding, physical source authentication, bit costs
and infinite-stream termination remain separate. These finite algorithmic
invariants do not remove the earlier finite-observation obstruction to general
quasivance recognition or assert completeness of the entire logic.
