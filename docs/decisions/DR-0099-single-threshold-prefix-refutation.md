# DR-0099 — Single-threshold summary of finite-prefix refutation

Date: 2026-10-08. Base: cac07c4. Status: scoped Lean proof checked.

## Claim card and counterexample check

The model is the scalar alpha/Theta threshold interface from DR-0027 and
DR-0088. DR-0098 equates full-prefix intensity refutation to the near-zero
monitor with `max N 2` entries. The remaining compression question is whether
that monitor needs every entry when its input is generated by one state.
The desired conclusion is exact Boolean output equality, followed by the
same semantic forcing criterion. It is not full-data reconstruction.

The near-zero thresholds decrease. A firing intensity bit at any index
therefore also fires at every later index. Thus a nonempty monitor is true
exactly when its last pair has at least one firing intensity bit.
`nearZero_intensity_bit_mono` proves this using the existing antitone
threshold theorem and DR-0098's monotonicity of silence. The proof handles
both intensity channels and non-strict threshold equality.

`RecognitionThresholdEndpoint.lean` defines `intensityBitRefuted` by one
Boolean disjunction and `endpointIntensityRefuted` by the selected index
`max N 2 - 1`. It proves:

```
finiteIntensityRefuted (countableThresholdSignature s) (n + 1) =
  intensityBitRefuted ((countableThresholdSignature s).nearZero n)

fullPrefixIntensityRefuted (countablePrefixSignature N s) =
  endpointIntensityRefuted (countableThresholdSignature s) N

PrefixForcesNonquasivance N s ↔
  endpointIntensityRefuted (countableThresholdSignature s) N = true
```

At N = 0, 1, 2 the selected index is 1, whose threshold is exactly 1/2.
`endpoint_small_prefix_eq_half` proves that the selected result equals the
permanent half-threshold reading already present in the full prefix. For
N > 2 the selected index is N - 1, already present in its near-zero list.
No new measurement is required by this observation-equivalence claim.

The arbitrary-data counterexample has its index-zero positive bit true
and its index-one bit false. Its two-entry reference monitor returns true
and the endpoint returns false. Kernel computation verifies both results;
`nonmonotoneThresholdData_not_realizable` proves no scalar state produces
this data. Therefore realizability must not be omitted from the equality
theorem. The index regression checks [0,1,2,3,10] -> [1,1,1,2,9].

## Boundary and remaining obligation

The summary suffices only for intensity refutation on realizable scalar
observations. A false result does not affirm quasivance. The earlier
finite-affirmation impossibility and lack of a uniform deadline remain.
The Boolean disjunction is computable once the pair is supplied; the
exact-real observation map remains noncomputable in this formalization.

This increment gives no time, bit-complexity or HashMap bound. Fetching the
selected pair is separate work: a list implementation may need a traversal,
and an abstract function need not supply constant-time indexing. A next
implementation obligation is a direct operation on supplied full-prefix
lists with a proved lookup/scan cost and checked correspondence to this
single-pair semantic summary. No core axiom or definition changed, and no
arbitrary-frame, physical-sensor, noise or general cognition claim follows.
