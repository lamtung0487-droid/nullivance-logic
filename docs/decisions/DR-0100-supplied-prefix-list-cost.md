# DR-0100 — Supplied-list refutation and exact traversal cost

Date: 2026-10-08. Base: 3628cf1. Status: scoped Lean proof checked.

## Claim card and candidate failures

DR-0099 proves that a selected pair summarizes intensity refutation of a
realizable scalar alpha/Theta prefix, but uses an abstract indexed function.
The remaining obligation is to implement the selection on the actual finite
`CountablePrefixData` list and prove both its verdict and traversal cost.
The input is supplied Boolean FOUR data, not an exact-real hidden state.
The conclusion must keep output equivalence and cost accounting separate.

For near-zero list lengths 0 and 1 the implementation selects the permanent
half-threshold pair. For lengths at least 2 it selects the last near-zero
pair by traversing the remaining list after the first two cells. Selection
uses the list itself, so a supplied length parameter cannot disagree with
the list. The structure bits and above-neutral list are not inspected.

The candidate counterexample is a two-entry list with a firing first
intensity bit and a silent last bit, with a silent central pair. The full
reference refuter accepts it, whereas the last-pair implementation does
not. `nonmonotonePrefixData_not_realizable` proves no prefix length and
scalar state generate this data. Empty,
singleton, two-entry and five-entry silent lists are separate executable
regressions; their counted outputs must be (false,2), (false,3),
(false,4), (false,7).

## Implementation and proof

`RecognitionThresholdListCost.lean` supplies an uncounted last-pair
specification, its counted recursive implementation, a short-prefix
selector, and `listPrefixIntensityRefutedCounted`. Structural induction
proves exact equality of the counted selector's value with its uncounted
specification for **every** supplied list. Separately, the range/map
last-element lemma and DR-0099 prove the implementation's Boolean verdict
equals the full-prefix reference result on data generated by a scalar
state. This yields the same `PrefixForcesNonquasivance` criterion.

The main counted theorem is:

```
listPrefixIntensityRefutedCounted (countablePrefixSignature N s) =
  (fullPrefixIntensityRefuted (countablePrefixSignature N s), N + 2)
```

The generic cost theorem holds without realizability and uses the actual
near-zero list length. The semantic theorem requires realizability; a
syntactic cost count cannot establish it.

## Cost model and scope

One unit means one nil/cons constructor inspection in the supplied-list
selector, including the terminal nil inspection. The short-prefix branch
charges one inspection for [] and two for a singleton. The longer branch
charges two inspections before its recursive traversal, then one per
remaining cons and one for nil. Exactly one further unit charges the
Boolean OR that produces the refutation bit. Thus N entries cost N+1
constructor inspections plus one Boolean OR, totaling N+2 model units.

The counter excludes generating observations, field projections, copying,
allocation, count arithmetic, machine representation, compiler optimizations
and elapsed time. The recursive counted implementation is not asserted to
have a constant stack bound. The value-erasure theorem proves correspondence
of outputs; it does not transfer this counter to an uninstrumented compiled
program. No optimality or universal speedup over a short-circuit scan is
asserted: this selector traverses every near-zero cell on its longer branch.
No O(1) lookup, bit-complexity, cryptographic, physical-sensing or
all-frame guarantee follows.

A false result still cannot affirm quasivance. Arbitrary inconsistent input
can disagree with the full refuter, as the preserved counterexample shows.
No core semantics or axiom changed. A next obligation is an incremental
selector retaining only the current endpoint and central pair, proving its
append invariant and separately counting updates rather than rescanning
already supplied observations.
